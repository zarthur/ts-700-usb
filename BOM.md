# Rev A BOM policy

This file is not a release BOM. Rev A targets JLCPCB/LCSC turnkey assembly. The release BOM must contain exact MPN, LCSC part number, reference, quantity, value, footprint, populated/DNP state, lifecycle/stock snapshot, and approved substitute policy.

Through-hole or mechanically inaccessible parts are permitted only when explicitly marked for manual installation in both BOM and assembly drawing. The schematic, PCB, BOM, and CPL must agree on each populated reference.

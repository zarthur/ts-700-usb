# KiCad source status

This is a portable KiCad 10 project scaffold. Its root and two child-sheet files intentionally contain no circuit until exact, measured endpoint values and component mappings are verified. They are placeholders for source organization, not electrical models and not eligible for ERC sign-off.

Use standard KiCad libraries through the project-local tables. Add a project-local custom symbol or footprint only when a selected verified part lacks an appropriate standard library item; do not add empty libraries.
